# Package review

1. **Title** ≤ 60 chars, makes a claim or names a puzzle; thumbnail adds an angle the title does not state.
2. **Thumbnail** at 1280×720 and shrunk to 168×94 (feed size): ≤ 4 words readable, one focal object, high contrast. Rank it blind against 5 real thumbnails from the niche.
3. **Promise** — the first 30 s of the video delivers on what title+thumbnail promise.
4. **Description** — 2-line summary, chapters with timestamps (from storyboard scene starts), sources list from the fact sheet, voice credit ("AI narration, Kokoro TTS").
5. **Policy** — YouTube altered/synthetic disclosure only if realistic synthetic footage of real people/events is shown (animated diagrams + TTS narration of an original script do not need it; disclosing anyway is harmless).
